# 読み上げくん

PDFやテキストを、スマートフォンの Chrome で最後まで読み上げるためのアプリです。

公開ページ: https://shomimasu1202-bot.github.io/yomiage/

## 使い方

1. 上のページを Chrome で開きます。
2. メニューから「ホーム画面に追加」すると、アプリのように開けます。
3. 「ファイルを選ぶ」で PDF・txt・md を選び、「再生」を押します。
4. 紙の本を撮影したPDFは、「縦書きの本」にチェックを入れます。

くわしくは [使い方.txt](./使い方.txt) を見てください。

## プライバシー

文書の中身は、この端末のブラウザの中だけで処理します。サーバーには送りません。
文字認識の仕組み（ライブラリとモデル）は、このリポジトリから読み込みます。

## 含めているもの

アプリ本体、アイコン、説明、および文字起こし・PDF表示用のライブラリとモデルだけです。
本の本文や、個人のファイルは入れていません。
